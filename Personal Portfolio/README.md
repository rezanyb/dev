# Reza NYB — Personal Portfolio

Single-page personal portfolio built with:

- Bootstrap 5.3
- Vanilla CSS
- Vanilla JavaScript
- Bootstrap Icons
- Google Fonts: Cormorant Garamond, Josefin Sans, Inter

## Files

- `index.html` — semantic page structure + SEO metadata
- `style.css` — design tokens, layout refinements, themes and responsive rules
- `script.js` — theme persistence, scroll effects and small interactions

## Before publishing

Replace:

- `https://example.com/` with the real canonical URL.
- `hello@rezanyb.dev` with the real email.
- Social `href="#"` values with real profiles.
- Demo project links and text.
- Demo image URLs with optimized WebP/AVIF local images when available.

For production, self-host/optimize images and fonts where appropriate, add `robots.txt`, `sitemap.xml`, favicon/app icons and JSON-LD for the person/website.
